Pour que le site fonctionne correctement, veuillez ajouter les images suivantes dans ce dossier :

1. hero-bg.jpg - Une image d'arrière-plan pour la section héro (idéalement une photo de chien ou de chat bien toiletté)
2. logo192.png - Le logo du site pour les appareils mobiles (192x192 pixels)
3. logo512.png - Le logo du site pour les appareils de bureau (512x512 pixels)
4. favicon.ico - L'icône du site (16x16, 32x32, 48x48 pixels)

Vous pouvez utiliser des images libres de droits provenant de sites comme Unsplash, Pexels ou Pixabay.
